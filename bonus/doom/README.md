Alright, so this isn't realy cybersecurity-related. You are playing Doom, but I mean how can you be mad when playing Doom? I have been planning on making this problem for 3 years so finally did it. Oh BTW I have been playing this game since I was like 7 so I considered making it super hard but then I decided to be nice. This is more of a fun, free bonus points challenge. Also I know this isn't actually the OG Doom. I didn't want to have license issues so I used the open-source freedoom for this!

Simply download the zip file, extract it. Then open a command prompt, change into the extracted directory and run the following command. The game should load, you hit new game and the difficulty doesn't matter. The flag is pretty obvious at the end you can't miss it.

```
gzdoom -iwad freedoom2.wad -file MAP01.wad
```

Submit the flag as `deadface{flag-text}`.
